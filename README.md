# MasterVerse local screens

۲۰ صفحهٔ Stitch به فایل‌های مستقل داخل `pages/` جدا شده‌اند. هر صفحه فونت محلی Yekan Bakh را به‌کار می‌برد و ناوبر ثابتِ کلیکی دارد؛ صفحهٔ جاری در ناوبر مشخص می‌شود.

## اجرا در VS Code

1. پوشهٔ `MasterVerse` را باز کنید.
2. یکی از فایل‌های `pages/*.html` را باز کنید؛ برای نمونه `pages/10-student-home-dashboard.html`.
3. روی **Go Live** در نوار وضعیت VS Code کلیک کنید.

`pages/shared.css` و `pages/shared.js` بین همهٔ صفحه‌ها مشترک‌اند. وزن‌های فونت در `pages/assets/fonts/` قرار دارند. Tailwind، آیکون‌های Material Symbols و تصاویر هنوز از CDNهای بیرونی بارگیری می‌شوند و برای آن‌ها اینترنت لازم است.
